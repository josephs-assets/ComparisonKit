# Comparison Kit

Documentation and support for **Comparison Kit**, an Unreal Engine 5.3 – 5.8 code plugin by Joseph's on Fab: data-driven 3D comparison videos (ranked columns, height and scale comparisons, versus, bar chart races, speed races and more), filled from a CSV or DataTable and rendered with Movie Render Queue.

- **Documentation:** https://josephs-assets.github.io/ComparisonKit/
- **Support:** [open an issue](https://github.com/josephs-assets/ComparisonKit/issues) - include your engine version, the format, and the Data Warnings text if it is about data.

This repository holds the documentation only; the plugin is sold on Fab.
