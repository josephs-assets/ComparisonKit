Every Blueprint node the kit adds, grouped by what you are doing. Node names are the names you type in the Blueprint search box; the text is the same as the Details and node tooltips. You do not need any code: Function nodes have white execution pins, Getter nodes are green pure nodes, Event / override entries are events you add in a Blueprint child (Event Graph > right-click, or Functions > Override), and Event dispatchers are bound with Bind Event or the green box in the Details panel.

52 Blueprint nodes (functions and events). Developer tooling and internal helpers are not listed.

1. Every comparison actor: data, timing, theme, camera, playback

CK Comparison Base

Node Kind Inputs Outputs What it does
Apply Style Seed Function - - Writes a seeded variation into this actor's camera and timing settings (camera side, angle and height, lead, entrances, dwell, closing orbit), so two videos from the kit do not share one grammar. The values stay editable.
Set Camera Path Actor Function New Path (Actor (object)) - Switches to a buyer spline without editing it. None restores the generated camera.
Set Time Of Day Function New Hour (Float) - Changes the inherited sun hour without rebuilding the scene. -1 restores the theme's original sun.
Set Theme Function New Theme (CK Theme (object)) - Switches the theme from a Blueprint or at runtime: copies its look and rebuilds with its set.
Apply Theme Function - - Copies the theme's look again (undoes look edits made since).
Use Suggested Theme Function - - -
Save Look To Theme Function - - Writes this comparison's current look into the Theme asset (save the asset afterwards).
Get Duration Getter (pure) - Return Value (Float) Length of the video, seconds: the format's own timeline plus every item's Hold Seconds (Time plays 0 -> this).
Fit Timing To Runtime Function - - Sets the per-item pace (Seconds Per Item, Round Seconds, Seconds Per Period) so the video lasts Target Runtime, then Fit Sequence.
Get Ocean Surface At World Point Getter (pure) Point (Vector), At Time (Float) Return Value (Transform) World-space surface point and orientation for this theme's water at a comparison time.
Set Time Function New Time (Float) - -
Rebuild Function - - Reload data and recreate the scene.
Fit Sequence Function - - Sets the Sequence's length to this comparison's duration and re-keys its Time track (0 -> duration, linear). With no Sequence (or a demo's sequence on a copy of a demo map) it first makes one next to your level, bound to this actor.
Get Item Count Getter (pure) - Return Value (Integer) -
Get Item Getter (pure) Index (Integer) Return Value (CK Item) Item Index in presentation order (the order the video shows them), e.g. for your own UI or events.
Get Focused Item Getter (pure) At Time (Float) Return Value (Integer) Index (presentation order) of the item being presented at AtTime, -1 when none is (title, closing shot).
Load Image File Function File Path (String) Return Value (Texture 2D (object)) Reads a PNG/JPG/TGA/BMP file into a texture once and keeps it for later calls (empty or unreadable = null).

10. Data and number-format library

CK Data Library

Node Kind Inputs Outputs What it does
Load Items From CSV Function File Path (String) Return Value (Boolean), Out Items (Array of CK Item), Out Error (String) Reads label,value[,country,note,image,mesh,animation,color,value_high,description,category,confidence,evidence,era,year] columns (header names are loose: case, spaces and '_' do not matter;
Load Items From CSV Columns Function File Path (String), Label Column (String), Value Column (String) Return Value (Boolean), Out Items (Array of CK Item), Out Error (String) Load Items From CSV with the columns named: a header or a 1-based column number; empty = automatic.
Validate Items Function - Return Value (Array of String), Items (Array of CK Item) Import guard: drops rows without a name or a finite value, trims names, empties placeholder fields ("N/A", "-", "?") so nothing shows them, ignores a value_high below the value, and lists duplicate names, negative values and double spaces.
Get Items From Data Table Function Table (Data Table (object)) Out Items (Array of CK Item) -
Load Series From CSV Function File Path (String) Return Value (Boolean), Out Series (Array of CK Series), Out Error (String) Bar chart race data. Long format: label,period,value[,country,image,color], one row per item and period ("year" also works). Wide format: label[,country,image,color] then one column per period with the period as its header (1990,1991,...).
Get Series From Data Table Function Table (Data Table (object)) Out Series (Array of CK Series) Row struct must be CKSeriesRow (long format).
Load Versus From CSV Function File Path (String) Return Value (Boolean), Out Stats (Array of CK Versus Stat), Out Error (String) A vs B rounds: stat,a,b[,suffix,lower_wins].
Load Subtitles From SRT Function File Path (String) Return Value (Boolean), Out Cues (Array of CK Cue), Out Error (String) Subtitles from an .srt file (WebVTT-style "00:00:01.000" times also read). Relative paths as for CSV files.
Sort Items Function Ascending (Boolean) Items (Array of CK Item) -
Normalize Value Getter (pure) Value (Float), Min Value (Float), Max Value (Float), Mode (CK Scale Mode) Return Value (Float) 0..1 height fraction. Linear and Volume use a zero baseline; Logarithmic spans MinValue..MaxValue.
Format Value Getter (pure) Value (Float), Decimals (Integer), Compact (Boolean), Prefix (String), Suffix (String), Unit Of (Float), Grouping (CK Digit Grouping) Return Value (Text) 1234567 -> "1,234,567" or, compact, "1.2M". UnitOf (non-zero) picks the compact unit instead of Value: a counting number keeps its final unit ("0.4B" on the way to "110.9B", never "731.0M"). Grouping picks the thousands separator.
