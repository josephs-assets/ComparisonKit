Data

My CSV is not found. A relative path is read from your project folder first, then from the plugin folder. Use the full path if the file lives elsewhere. Look at Data Warnings: the first line says what was read.

The kit picked the wrong columns. Type the header (or its 1-based number) into Csv Label Column and Csv Value Column. Data Warnings starts with a CSV read line naming the columns it took.

Numbers like 1,234 read as 1.234. If every number in a ; file looks like 1,234, the comma is read as a decimal mark. Write the numbers with a clear decimal point, or use a comma-separated file. See Data.

Rows are missing. Open Data Warnings. Rows without a number, total rows, groups of countries (World, High income, ...) and placeholders (n/a, -) are left out on purpose. Max Items may also cap the list.

A country has no flag. Add its spelling to a row's Names in DT_CK_Flags, separated by |. The first name is the display name.

The list is too long for one video. Set Max Items.

Sequencer and render

I changed the data and the sequence is too short or too long. Press Fit Sequence again after every change to data, timing or aspect.

My retiming disappeared. Fit Sequence rewrites the Time track. Retime after your last Fit Sequence, or use the hold column.

The render is much slower than the preview. Check that Virtual Shadow Maps is on (Project Settings > Rendering). Without them scenes render about three times slower. Also see Rendering for editorless rendering and Fully Load Used Textures.

The Shorts render is cropped. The actor's Aspect and the render preset must both be 9:16.

Fit Sequence warns about fast cuts. Slow the timing until the warning in Data Status goes (no cut faster than three per second).

Packaged builds

The packaged game shows old data. CSV files are not cooked; a packaged game plays the rows saved with the level. Open the level in the editor, check Data Warnings, save it, then package again. Or use a Data Table (row struct CKItem), which is cooked. Pictures given as file paths are not cooked either: import them as textures and use their asset paths, or add their folder under Project Settings > Packaging > Additional Non-Asset Directories To Copy.

Content

I cannot see the demo maps. Enable Show Plugin Content in the Content Browser settings, then open Plugins > Comparison Kit > Maps.

The set is in my way. Untick Build Set to keep your own level's lights and scenery.

I changed something through Blueprint and nothing happened. Call Rebuild. The Details panel rebuilds by itself, Blueprint changes do not.

Engine versions

The same features run on every listed engine. Differences come from the engine's own Text3D plugin:

Engine Subtitles and the description lines on label cards
5.5 to 5.8 A long line wraps (up to three lines on a card), then scales down if it still does not fit.
5.3 and 5.4 Text3D cannot wrap: a long line is scaled down to fit on one line. Short text looks the same.

Names, values and titles fit the same way on every engine (scaled down when too wide).

Text3D before 5.6 is the older Beta version of the plugin; the kit sets it up the same way on every engine.

Support

Open an issue on the support page with your engine version, the format, and the text of Data Warnings if the problem is about data.
