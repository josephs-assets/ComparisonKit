Spec Card

What it shows. A 4-5 second loopable Shorts card: a heavy title over two to four items stacked down a 9:16 frame, each with one spec block (flag and name, value, two stat lines), or two items split top and bottom with zig-zag spec blocks and a VS line. The camera is static and everything is in the world, lit by the theme.

Actor: CK Spec Card. Demo maps: L_CK_SpecCard_StudioGlass_Shorts (Stack), L_CK_SpecSplit_StudioGlass_Shorts (Split).

Data

A normal item table. Pictures come from the item's image column (cut-out card); an item with a static mesh shows the model, swaying round a three-quarter view so the loop returns to its first frame. The two stat lines use the stat1 and stat2 columns. Max Items caps the stack (2 to 4 shown; Split shows two).

Key settings

Field Default What it does
Layout (Layout) Stack - (Details: Comparison | Spec Card)
Show Value Line (bShowValueLine) true Show the item's value as the first spec line (Value Prefix / Suffix apply: "Max speed: Mach " + 2.0). (Details: Comparison | Spec Card)
Sway Degrees (SwayDegrees) 12 Model items turn this far either side of a three-quarter view over one loop; pictures stay still. (Details: Comparison | Spec Card)
Short Seconds (ShortSeconds) 4.5 Length of the Short: every part is back at its first pose at the end, so it replays seamlessly. (Details: Comparison | Timing)
Picture Mesh (PictureMesh) - Card an item's Image is drawn on (upright, faces +Y, base at Z 0) and its material ("Tile" = the picture). (Details: Comparison | Spec Card | Look)
Picture Material (PictureMaterial) - - (Details: Comparison | Spec Card | Look)
Backdrop Image (BackdropImage) - Optional full-frame picture behind the items (a pale world map). Empty: the theme's set shows. (Details: Comparison | Spec Card | Look)
