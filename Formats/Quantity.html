Accumulator and Lap

What they show. Several rows share one clock. In Accumulator each row earns a quantity per second and its stack grows ("$90,000 per second"). In Lap each row is a circuit period and a marker circles its track, with lap count and fraction updating live.

Actor: CK Quantity Comparison. Demo maps: L_CK_Accumulator, L_CK_Lap.

Mode Row value Example in the demo
Accumulator units earned per simulated second At $90,000/s and $270,000/s, eight seconds give $720,000 and $2,160,000
Lap seconds needed for one complete circuit After eight seconds, a 2.5 s period gives three laps plus 20 %; a 4 s period gives two complete laps

Data

Use Items, a CKItem DataTable or a CSV with label,value columns (priority: DataTable, CSV, inline). Set Mode to reinterpret the values, and call Rebuild after changing a source, the mode, the unit mesh or a period in Blueprint. Rank Order and Max Items select the rows when the data holds more than four entries. Lap times must be at least 0.001 seconds. Zero is valid for an earning rate. Sample: SampleData/quantity_rows.csv.

Key settings

Setting What it does
Mode Accumulator or Lap
Run Seconds duration of the action
Clock Speed simulated seconds per presentation second
Unit Value amount represented by one prop
Unit Budget maximum visible units; if any row exceeds it the actor groups the units by a common factor for every row, and one partial unit grows in height for the remainder (the number keeps the full value)
Unit Mesh, Platform Mesh the prop and the pallet (assign a Platform Mesh to replace the supplied one)
Lap Radius sizes every path equally
Orbits, Centre Mesh Lap: rows circle a shared centre, each radius from its period
Clock Unit the clock's unit when values are not seconds, for example "Earth days"
Tracking Width how far the camera travels sideways between rows; zero keeps the view centred during the opening push. Square and portrait framing limit it
Loop Ending return to the opening frame

The intro starts the clock and the outro holds the result. Set Time supports forward and reverse scrubbing.

Blueprint

Get Elapsed At Time (the shared clock), Get Amount At Time (a row's accumulated value or fractional laps), Get Display Unit (the effective unit after grouping), Get Lap Point (marker position in actor-local centimetres) and Get Readout At Time (the displayed text). Row indices refer to the sorted display order.

The set

Both demos use the Warehouse theme: the timber pallet, a two-metre concrete floor scan and a photographed industrial interior. The floor and foreground cargo are scene geometry; the distant building is panoramic scenery. See Credits.
