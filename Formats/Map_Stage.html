Map Stage

What it shows. Country shapes with a card each, on a rotating globe, a flat map or a true-size overlay: "how big is X really?"

Actor: CK Map Comparison. Demo map: L_CK_MapStage_Shorts (a 9:16 map; there is no landscape copy). The camera follows the comparison and holds its final frame.

Data

Each row needs a display name, a numeric value and a country code. The value is the number on the card. The atlas accepts a three-letter Natural Earth identifier or its two-letter alias where available. Unsupported codes produce a Data Warning.

label,value,country
Brazil,8540946,BR
Greenland,2189750,GL
Australia,7692024,AU

These values are approximate square kilometres. Set Value Suffix to km2 (or any unit); for another metric, enter its values and units in the same fields. Sample: SampleData/map_countries.csv.

Key settings

Map View switches between Flat, True Size and Globe. After changing the view or the data in a Blueprint, call Rebuild; the Details panel rebuilds by itself.

Setting What it does
Map View Flat, True Size or Globe
Reference Country the blue silhouette in True Size view (default GL)
Seconds Per Country the beat of each card
Globe Sweep Degrees how far the globe turns during each card; zero centres the chosen region during the hold
Globe Opening Distance Scale the camera's opening push; set it to 1 to keep the globe at a constant size
Atlas the country atlas asset
  • Flat highlights the row on a geographic map. Globe wraps the same country IDs onto a sphere and turns across the short longitude interval at the date line.
  • True Size puts both outlines at the same kilometres per screen unit, each shape centred on its bounds. Blue marks the reference country, amber the active country, plum their overlap. On the reference country's own card the matching outlines appear once, in amber.
  • The demo's opening camera path tracks across the globe during the first card. Clear Camera Path Actor to use the generated camera.
  • Get Shape Area Km2 returns the mapped area for a code; Get Country At Time returns the active row's code.

The included atlas is Natural Earth 1:110m Admin 0, version 5.1.1: 177 generalized regions, with islands and interior rings. Area figures depend on that generalization and use a sphere of equal surface area to Earth. See Credits.
