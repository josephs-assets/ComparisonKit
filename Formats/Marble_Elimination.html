Marble Elimination

What it shows. Marbles roll down a spun-steel funnel and fall out one by one in score order until a single winner remains. A lower card names the contender and its score; a status strip counts the marbles still in play and announces the winner.

Actor: CK Marble Elimination. Demo map: L_CK_MarbleElimination_Shorts (9:16). In the supplied round Crimson, Amber and Jade leave in that order and Azure wins with 94 points.

Data

Give each marble a name and a score: Items, a CKItem DataTable or a CSV. Priority: DataTable, then CSV, then inline items. Set the inline row's colour to identify the marble on screen. Call Rebuild after changing the source in Blueprint.

label,value
Azure,94

Key settings

Setting What it does
Rank Order Highest First: the largest score survives. Lowest First: the smallest survives. A tie lets the earlier input row survive longer
Max Items the course supports 1 to 6 marbles; more rows keep the six best for the ranking and add a Data Warning
First Exit Seconds time from the end of the intro to the first exit (demo: 3.40 s)
Seconds Per Exit spacing of later exits (demo: 1.65 s)
Outro Seconds hold after the winner leaves the funnel (demo: 1.25 s)
Loop Ending return to the opening frame
Display Scale sizes the funnel and the marbles together
Orbit Degrees camera travel
Lift Winner the winner rises out of the funnel and hovers over it

The supplied course holds six Chaos simulations recorded at 120 Hz, one per supported row count. The presentation assigns rows to the recorded paths by survival rank and interpolates the sampled position and rotation, so the same scores always give the same winner in Play, when scrubbing backward and in a rendered movie. The saved demo plays from the course asset and needs no editor scripts at runtime.

Blueprint

Get Exit Time (by sorted row index), Get Contenders At Time, Get Winner At Time and Get Physics Frame At Time. Use Set Time to seek: for example 5.10 s in the supplied round shows two contenders and 7.00 s shows Azure named as winner.
